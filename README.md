# becario-reels-test1

## ¿Qué hace este repositorio?
`becario-reels-test1` funciona como un asistente automatizado ("becario virtual") enfocado en la producción masiva de contenido en formato vertical (Instagram Reels, TikTok, YouTube Shorts). Toma fragmentos de video o contenido extenso y los procesa para adaptarlos a la relación de aspecto 9:16 con subtítulos dinámicos y recortes rápidos.

## Características
- **Adaptación 9:16:** Conversión y reencuadre automático de videos al formato vertical.
- **Subtitulado Dinámico:** Inserción y sincronización de subtítulos de alto impacto para redes sociales.
- **Automatización de Edición Corta:** Generación rápida de clips listos para publicar sin intervención manual constante.

## Requisitos Previos
- Python 3.8+
- FFmpeg
- Credenciales o claves de API (en caso de utilizar servicios externos de transcripción o IA)
